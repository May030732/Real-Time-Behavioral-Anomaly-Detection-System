# 🩺 ESP32 穿戴式多模態生理訊號與姿態監測系統 (ESP32 Multi-Sensor Biometric & IMU System)

本專案基於 **ESP32 D1 Mini** 開發板，整合了光學心率血氧感測器 (**MAX30102**)、六軸慣性感測器 (**MPU-6050**) 以及皮膚電阻感測器 (**Seeed Grove – GSR Sensor**)。系統具備高採樣率生理訊號捕捉、指數平滑濾波、藍牙無線數據傳輸（Bluetooth Serial）與即時串口監控功能，可用於健康監測、情緒/壓力分析及跌倒/衝擊檢測等穿戴式應用。

---

## 🛠️ 硬體元件清單 (Hardware Components)

| 元件名稱 | 模組型號 / 規格 | 通訊介面 / 訊號類型 | 主要用途 |
| :--- | :--- | :--- | :--- |
| **主控板** | ESP32 D1 Mini | Wi-Fi / Bluetooth Dual-Core | 核心數據處理、藍牙傳輸與感測器調度 |
| **六軸慣性感測器** | MPU-6050 | I2C (0x68) | 捕捉三軸加速度 (Acc) 與三軸角速度 (Gyro) |
| **心率血氧感測器** | MAX30102 | I2C (0x57) | 捕捉紅光 (Red) 與紅外光 (IR) PPG 光學心跳訊號 |
| **皮膚電阻感測器** | Seeed Grove – GSR Sensor | 類比電壓 (Analog Signal) | 監測皮膚導電度 (uS) 與情緒/生理激發狀態 |
| **GSR 手指套件** | 3.5mm Jack 轉手指貼片 | 生物電阻接觸 | 配戴於食指與中指捕捉皮膚微量汗腺變化 |

## 📌 詳細引腳連接對照表 (Pin Mapping)

根據 ESP32 D1 Mini 的腳位配置，整體接線架構如下：

                         ┌───────────────────────┐
                         │     ESP32 D1 Mini     │
                         └───────────┬───────────┘
                                     │

```

[Grove GSR Sensor]                     │
VCC ───────────────────────────────►│ 3V3 (3.3V 電源)
GND ───────────────────────────────►│ GND (接地)
SIG (Signal) ──────────────────────►│ IO34 (ADC0 / GPIO34, 左側倒數第4針)
TP4 ───────────────────────────────►│ NC (不連接/懸空)
│
[MPU-6050 & MAX30102 共用 I2C 總線]    │
VCC (MPU-6050) ────────────────────►│ 3V3
VIN (MAX30102) ────────────────────►│ 5V  (⚠️ 必須接 5V 以確保 LDO 穩壓足夠)
GND ───────────────────────────────►│ GND
SCL (兩模組並聯) ─────────────────►│ IO22 (I2C SCL, 右上第3針)
SDA (兩模組並聯) ─────────────────►│ IO21 (I2C SDA, 右上第4針)
```


### 🔍 引腳詳細說明：
1. **GSR Sensor (類比訊號)**：
   * **SIG (Signal)** 連接至 **`IO34`** (ADC0 / ADC1 頻道)，避開開啓 Wi-Fi/藍牙時會受干擾的 ADC2 引腳。
   * **TP4** 為模組內部測試點，無須接線。
2. **I2C 匯流排 (MPU-6050 + MAX30102)**：
   * 兩模組 **SCL (`IO22`)** 與 **SDA (`IO21`)** 以並聯方式共用同一組 I2C 總線。
   * **供電注意事項**：MAX30102 模組建議接至 **`5V`**，避免因板載 3.3V LDO 壓降造成 3.3V 供電不足而導致 I2C 通訊斷線 (`Error -1`)。

## 📚 模組與函式庫架構說明 (Library Architecture)

本專案採模組化物件導向架構設計，包含以下自訂與第三方庫：

### 1. `GSR_Sensor` (自訂皮膚電阻模組)
* **`GSR_Sensor(uint8_t pin, float smoothFactor)`**：建構子，設定 ADC 腳位與指數平滑係數（預設 0.15）。
* **`void begin()`**：初始化 ADC 設定（12-bit 解析度：0~4095、衰減度：ADC_11db/0~3.3V 輸入範圍）。
* **`uint16_t readRaw()`**：進行 5 次超快速採樣去雜訊，回傳原始 ADC 數值。
* **`float readSmooth()`**：採用**低通指數移動平均濾波 (Exponential Moving Average Filter)** 計算平滑數值，降低干擾。
* **`float readConductance()`**：將讀取到的電壓依據分壓公式轉換為**皮膚電導度 (微西門子, µS)**。

### 2. `MPU6050_Module` (姿態/加速度模組)
* **`init_MPU6050()`**：初始化 MPU-6050，設定量程與採樣率。
* **`read_MPU6050()`**：讀取並回傳封裝好的 `MPUData` 結構（包含 $a_x, a_y, a_z$ 加速度與 $g_x, g_y, g_z$ 角速度）。

### 3. `Max30102_Module` & `Bio_Algorithm` (光學脈搏與演算法模組)
* **`init_MAX30102()`**：設定 MAX30102 光學發射功率與採樣模式。
* **`read_MAX30102()`**：讀取紅光 (Red) 與紅外光 (IR) 的反射強度。
* **`process_PPG(red, ir)`**：執行即時 PPG 訊號處理解析，當檢測到脈動瞬間時將 `result.isBeat` 設為 `true`，並更新 BPM (心率) 與 SpO2 (血氧)。

### 4. `BluetoothSerial` (ESP32 原生藍牙庫)
* 開啟傳統藍牙 (Classic Bluetooth) 功能，廣播名稱為 **`ESP32_Blanc`**，用於無線同步發射生理數據。

## ⚙️ 系統工作流程與任務時序 (Task Scheduling)

本專案在單一 `loop()` 中採用**非阻塞式計時器 (Non-blocking Timers)**，將不同採樣率的任務完美分流，確保生理訊號不失真：


```

```
                ┌─────────────────────────────────────────┐
                │            ESP32 Main Loop              │
                └────────────────────┬────────────────────┘
                                     │
    ┌────────────────────────────────┼────────────────────────────────┐
    │ 100Hz (10ms)                   │ 20Hz (50ms)                    │ 2Hz (500ms)
    ▼                                ▼                                ▼

```

┌───────────────────────────────┐┌───────────────────────────────┐┌───────────────────────────────┐
│  - 讀取 MPU-6050 IMU         ││  - 讀取 GSR 平滑值與 µS       ││  - 印出 IMU 三軸與 Gyro 狀態   │
│  - 讀取 MAX30102 PPG 光學值    ││  - 輸出 Serial Plotter 波形  ││  - 印出 MAX30102 原始強度      │
│  - 執行 process_PPG() 脈搏計算││    (GSR_Smooth, Conductance)  ││  - 避免 UART 緩衝區溢位       │
└───────────────┬───────────────┘└───────────────────────────────┘└───────────────────────────────┘
│
[偵測到心拍 trigger]
│
▼
┌───────────────────────────────┐
│ - 格式化心率(BPM)與血氧(SpO2) │
│ - 發送至串口 (Serial)         │
│ - 發送至藍牙 (Bluetooth)      │
└───────────────────────────────┘

```

1. **主採樣迴圈 (100Hz / 10ms)**：
   * 高速讀取 MPU6050 與 MAX30102 數據並進行演算法即時計算，確保光學波形特徵點不漏抓。
2. **GSR & Serial Plotter 輸出 (20Hz / 50ms)**：
   * 每秒輸出 20 次 GSR 數據，可在 Arduino Serial Plotter (串口繪圖器) 上呈現出極為平滑的電導度曲線，且不佔用過多 UART 緩衝區。
3. **心跳觸發報告 (Event-Driven)**：
   * 僅在 `process_PPG` 捕捉到心拍瞬間（`isBeat == true`）時插播輸出，大幅節省通訊頻寬。
4. **終端機狀態除錯 (2Hz / 500ms)**：
   * 每 500ms 控制台更新一次文字檔狀態，避免字串洗版導致主程式被 `Serial.print` 卡死。

## 💻 快速開始 (Quick Start)

### 1. 開發環境配置
* **IDE**：Arduino IDE 2.x 或 VS Code + PlatformIO
* **開發板選擇**：`ESP32 Dev Module` 或 `WEMOS D1 MINI ESP32`
* **I2C 速率設定**：若傳輸距離較長，請於 `Wire.begin(21, 22);` 後加入 `Wire.setClock(100000);` 降至 100kHz 提升抗干擾能力。

### 2. 測試藍牙連接
1. 燒錄完成後，開啟手機藍牙搜尋新裝置。
2. 配對名為 **`ESP32_Blanc`** 的裝置。
3. 開啟任意藍牙 Serial App (如 *Serial Bluetooth Terminal*)，即可無線接收即時心率與血氧觸發報告。

## ❓ 常見問題排查 (Troubleshooting)

* **Q: 串口出現 `[Wire.cpp:499] requestFrom(): i2cWriteReadNonStop returned Error -1` 怎麼辦？**
  * **A**：此為 I2C 通訊無回應錯誤。請檢查 MAX30102 的電源是否已接至 ESP32 的 **5V** 腳位（接 3.3V 常因 LDO 壓降導致電源不足斷線），並確認 SDA/SCL 杜邦線無鬆動。

* **Q: MAX30102 輸出的 PPG_IR 與 PPG_RED 一直是 0？**
  * **A**：請確認手指是否貼合感測器視窗，並確保晶片供電正常。若仍為 0，請檢查 I2C 位址是否衝突或模組損壞。

* **Q: GSR 數據讀取卡在 0 或 4095？**
  * **A**：請確認 GSR 是否確實插在 **`IO34`**，且 ESP32 供電接地 (GND) 與 GSR 模組共地；確認手指套是否已插入 3.5mm 插孔。
